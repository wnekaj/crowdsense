Crowdsense. / email composer
Internal tool — writes the Thursday and Sunday subscriber email for pasting into Buttondown or Mailchimp

The email goes out twice a week and catches subscribers up on the questions since the last one: Thursday's has Sunday to Wednesday (four), Sunday's has Thursday to Saturday (three). It never contains an answer; the link opens the archive, where every past question can be played. Paste the HTML into Mailchimp's code view, or the Markdown into Buttondown. Buttondown and Mailchimp append the legally required unsubscribe link automatically, so don't add one by hand. This page is unlisted but public; it never shows an answer.
